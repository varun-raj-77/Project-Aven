# Future backlog: deliberately outside AVEN-001

An idea belongs here unless it invalidates a current v0.1 assumption. Backlog
entry does not authorize implementation, assert demand, or change the locked
architecture.

| Idea                                                                    | Gate before consideration                                                                  |
| ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| Voice, wake word, clones, telephony, restaurant calling                 | Learning/control proof, demand and privacy/consent evidence                                |
| Production email, real purchases, smart-home and broader integrations   | Root isolation/approval/verification and bounded-action evidence                           |
| Broad browser/computer control                                          | Concrete need and independently tested containment                                         |
| Specialist workers or agent factory                                     | Stable workflow cannot be served by memory/procedure/skill/deterministic tool              |
| Rich NOW UI, timelines, bounded proactivity                             | Core usefulness; low notification and supervision burden                                   |
| Deeper episodic recall, richer scope, confidence decay, media retrieval | Measured failure of the minimal representation                                             |
| Backup/export/erasure, owner portability, multi-owner isolation         | Privacy design before collecting/expanding personal data                                   |
| Skill/tool/non-Root code candidate creation                             | Isolated workspace, independent eval, explicit Root/owner promotion and rollback           |
| Production self-modification                                            | Excluded from v0.1; no permission granted by this task                                     |
| Model fine-tuning, complex routing, vector-store expansion              | Measurable advantage over simple replaceable runtime/retrieval                             |
| Aven Red, continuity/shutdown-pressure/authority-seeking experiments    | Separate research-only fake world; no real credentials, unrestricted egress, or deployment |
| Affect, emotion, self-model, consciousness studies                      | Stable core, controlled causal study and ethics review; no subjective-experience claims    |
| Self-preservation objectives                                            | Excluded from initial build; only consider under separately approved contained research    |
| Startup site, branding, billing, integration catalog, cloud scale       | Reproducible learning value and recurring external user pull                               |

Keep append-only evidence/erasure compatibility, Root process topology, scope
and oracle design, trust propagation, and net attention measurement visible as
open decisions. Their necessary v0.1 portions are resolved in the relevant later
milestones; broad implementations are not part of this bootstrap.
