# User research: proposed protocol

**Status: no interviews or user findings recorded.** Source: Master Description
sections 11, 17, and 22. Do not convert design aspirations or research fixtures
into observations about real users.

Start with explicitly consented owner dogfooding after the runtime exists. Later
interviews should ask about concrete recent incidents: what had to be
re-explained, which preference was applied in the wrong context, what was
forgotten, what action was distrusted, and how much supervision or workaround
time was required. Avoid hypothetical "would you use this?" validation.

## Evidence to record later

| Field                                             | Purpose                                                          |
| ------------------------------------------------- | ---------------------------------------------------------------- |
| Pseudonymous participant ID, consent/scope/date   | Establish provenance and retention permission                    |
| Concrete task/incident and current workaround     | Ground pain in behavior                                          |
| Corrections, repetitions, review/approval minutes | Measure cost and net attention saved                             |
| Expected application and non-application scope    | Avoid making universal preferences from one example              |
| What was distrusted, ignored, missed, or removed  | Measure dependence/pull and failure conditions                   |
| Counterexamples and alternative explanations      | Challenge the product hypothesis                                 |
| Source references and limitations                 | Separate observation, quotation, interpretation, and speculation |

Do not store real names, transcripts, sensitive histories, or consent records in
this public source scaffold. Define secure local storage, minimization,
deletion, export, and sharing permissions before collection. Owner data for
evaluation must be specifically consented; synthetic fixtures are not user
validation.

Compare B and C under equal task exposure and account for all profile-editing,
candidate-review, labeling, correction, and approval time. Report evidence that
contradicts the thesis. Recruitment, outreach, interviews, and participant
incentives are deferred; this document does not authorize contacting anyone.
